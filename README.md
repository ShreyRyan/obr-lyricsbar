# 网易云歌词同步 — Owlbear Rodeo 扩展

将网易云音乐歌词实时滚动显示给跑团玩家。**零依赖**，无需安装 Docker 或 Node.js。

## 安装

1. 打开 [Owlbear Rodeo](https://owlbear.app/profile)
2. 进入 Profile → 点击 **Add Extension**
3. 填入扩展地址：https://shreyryan.github.io/obr-lyricsbar/manifest.json
4. 打开扩展

注：项目部署在github，如果安装不上，请科学上网

## 使用说明

### DM

**准备歌词**
1. 获取歌曲的 LRC 歌词文件（`.lrc`），可使用以下任一方式：
   - 网易云客户端播放时在歌词页面导出
   - 使用在线歌词提取工具（搜索"LRC 歌词下载"）
   - 复制网易云歌曲 ID，访问歌词提取网站
2. 点击 OB 左上角「歌词同步」按钮打开面板
3. 填写歌曲名和歌手（选填，用于 PL 端显示）
4. 拖拽 `.lrc` 文件到导入区，或粘贴 LRC 内容后点击「解析歌词」
5. 看到「✅ 已解析 N 句歌词」即导入成功

**开始同步**
1. 在网易云客户端播放该歌曲
2. **同时**在插件中点「▶ 开始」
3. 如歌词与音频不同步，使用 `+0.1s` / `-0.1s` 微调
4. 需要中断歌词时使用「⏸ 暂停」/「▶ 继续」

### PL
**无需任何操作！**
